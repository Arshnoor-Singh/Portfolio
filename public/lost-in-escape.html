Lost in Escape

Lost in Escape is a puzzle game in which the Player has to solve puzzles to leave the test chamber that they are trapped in and uncover secrets along the way.

You can download and play the game here : Itch.io

I played the role of a designer and programmer in this project. I made the following contributions to this project.

  1. Interaction System - Object interaction and contextual prompts that appear over objects as player gets closer to them or looks right at them
  1. Sublevel System Setup - A system that helped create a relatively large team create small sublevels in shared 3D space without causing Source control conflicts
  1. Level Selection System - A system to select individual levels if the player chooses to play/replay a particular level instead of playing the whole game
  1. Source Control - Set up, and Managed the source control of the project using GitLab
  1. Final Level of the Game - Designed and Programmed the final level of the game (Shown in images). Created the logic of all assets needed using blueprints and designed the level layout.
  1. Build Preparation - Resolved build issues and made sure a proper build was generated in given time
