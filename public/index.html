Driving License? Never heard of it

STEAM LINK - Be sure to check out the steam page and leave a Wishlist if you like this. Thank you!

This is a personal project of a driving game where everyone drives like a lunatic. This is a solo project, I’ve developed all systems and mechanics my self in Unity.

  1. Driving System - Created a driving systems which uses torque curves and gearboxes to mimic a semi realistic driving experience
  1. Performance Design - Created and programmed multiple different upgradable items such as Engines, Transmissions, Tires, Color, Forced Induction (Turbo / Superchargers), Nitrous and abilities.
  1. Open World Events - A system to allow the player to explore an open world map where the player can choose to start whichever event they please, and win it.
  1. Open World Optimization - Applied the following methods to improve data streaming for the large open world level - Occlusion Culling, Batching, Draw Calls Optimization, Splitting areas into subscenes to precisely control the loading and unloading of certain areas and assets
  1. Data Persistence - System to save and Load progress of the player over the course of the game
  1. AIs - Programmed and Designed various AI behaviors such as simple NPC drivers, Rivals drivers, Aggressive AI drivers, Pursuing drivers

Contact Below

Contact below is a story based Submarine game. The player plays as a Submarine Operator in the ocean of an alien planet. The game explores the genre of Cosmic Horror and Existentialism. The game is being made using Unreal Engine Blueprints.

Said work includes:

  1. Game Design - This goes over the various decisions regarding the game mechanics and balance. Feature adjustment like noise generation, fish AI behavior, AI response behavior, Submarine functions like propulsion, turning radius, electronic systems, environmental events and so on. All of these details can be seen in the design documentation given below.
  1. Programming - The programming of the game is done using Blueprints.
  1. Art - All of the UI art is being creating using a combination of Photoshop and Blender.
  1. Audio - Recording and Editing various kinds of underwater sounds, submarine and UI interaction sounds for the game.
Demo - Check out the free to play demo at this link - Contact Below Demo
Game Premise - The game is about you controlling a submarine in an alien planet with an objective to retrieve some valuable intel from the ocean’s bed. There are Enemy Submarines in the vicinity and Hostile Wildlife. Both of these entities are capable of destroying your Submarine.
Game Objective - The player needs to be stealthy and Silent to avoid being detected by enemy subs or hostile alien wildlife. The player uses various things like SONAR, Torpedoes, Mines and many other items to retrieve the intel and exfil or eliminate the enemy.

The objective of this game is to be an intense stealth, strategy and turn based game.

The images on the side are under-development screenshots for the game when the Submarine is in Stealth Mode.

Turtle Racer

Turtle Racing is an educational undersea experience where you speed through an ocean trench and use your knowledge of marine life to reach the finish before your opponent!

I helped create multiple background systems like:

  1. Question generation - This system pulls random questions and answers from a database that can be edited at any time during the life cycle of a game. Generated questions can then be shown on the screen live as the player progresses through the level
  1. Race state control - This system dynamically increases or decreases the speed of the opponents to emulate as if the player is indeed racing with a rival/opponent
  1. Player speed manager - This system increments/decrements player speeds when the player receives buffs/debuffs
  1. Level streaming - This system essentially tags different level components with unique keywords and loads them in or out depending upon your location in the level to ensure good performance

Oyster Matching Card Game

Oyster matching card game is a simple educational game about learning different body parts of an Oyster.

This game is in a card matching game format. It’s an incredibly simple concept with the goal of helping students memorize the anatomy of an Oyster in a fun easy manner.

My contribution to this project was-

  1. Card Scriptable Objects - Created scriptable objects in Unity that served as a base template for all of the cards of the game.
  1. Randomization and Distribution - Created the system to randomize the cards and the data inside them to create a new deck of cards each game.
  1. UI Layout - Created and tested the UI layout to work on multiple android devices.
